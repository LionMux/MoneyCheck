# Мобильные приложения для учета личных финансов

**Мобильные приложения для учёта личных финансов** — класс программного обеспечения для смартфонов, предназначенный для планирования бюджета, учёта доходов и расходов, анализа транзакций и управления платежами.

## Ключевые факты

- Актуальность таких приложений растёт в условиях стремительного развития цифровых технологий и увеличения числа мобильных пользователей.
- Основные функции (по данным источника):
  - составление бюджета;
  - анализ транзакций;
  - напоминания о платежах;
  - [[concepts/multivalyutnost]];
  - защита данных с помощью пароля.
- Примеры приложений на платформе [[concepts/android]]: [[concepts/finansy-byudzhet-rashody]], [[concepts/coin-keeper]], модуль в приложении [[concepts/tinkoff]].
