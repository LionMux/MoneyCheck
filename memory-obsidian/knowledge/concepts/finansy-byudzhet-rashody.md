# Финансы — бюджет, расходы

**«Финансы — бюджет, расходы»** — мобильное приложение для учёта личных финансов на платформе [[concepts/android]], доступное в [[concepts/google-play-store]].

## Ключевые факты

- **Охват:** более **5 млн скачиваний**, пользовательский рейтинг **4,9**.
- **Преимущества:**
  - Понятный интерфейс;
  - Детализация операций;
  - [[concepts/multivalyutnost]];
  - Безопасность (защита данных с помощью пароля).
- **Недостатки:**
  - Платный контент;
  - Наличие рекламы;
  - Отсутствие информации о геолокации мест, где пользователь потратил деньги.
