# Coin Keeper

**Coin Keeper** — мобильное приложение для учёта личных финансов на платформе [[concepts/android]].

## Ключевые факты

- На момент написания источника приложение находилось в стадии [[concepts/beta-testirovanie]].
- **Преимущества:**
  - [[concepts/multivalyutnost]];
  - Автоматическое распознавание SMS-сообщений от банков;
  - Уникальные анимации интерфейса;
  - Защита данных о финансах с помощью пароля.
- **Недостатки:**
  - Платный контент;
  - Простой дизайн;
  - Отсутствие информации о геолокации трат.
